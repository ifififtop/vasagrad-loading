ВАСЯГРАД — экран загрузки Garry's Mod
======================================

Состав:
- index.html — сам экран загрузки
- music/track-01.mp3 — «Фура переехала мои мозги»
- music/track-02.mp3 — «Мистер токон пиздабол»
- music/track-03.mp3 — «Доброград крашат»

ВАЖНО: sv_loadingurl должен указывать на публичный HTTPS-адрес, доступный игрокам.
Сам ZIP нельзя просто указать в sv_loadingurl. Сначала распакуй его и загрузи
всю папку так, чтобы index.html открывался по прямой ссылке, а папка music
лежала рядом с index.html. Проверь ссылку в обычном браузере.

Когда у тебя будет адрес страницы, добавь в server.cfg:
sv_loadingurl "https://ТВОЙ-ДОМЕН/vasagrad/index.html"

Либо укажи этот адрес в соответствующем поле панели Pterohost, если оно есть.
После этого перезапусти сервер и проверь вход с другого аккаунта/компьютера.

Музыка начинает играть после нажатия ▶: браузеры могут блокировать
автовоспроизведение звука до первого действия пользователя. Кнопка ↻
переключает следующий трек. Уровень громкости по умолчанию 35%.

Полоса загрузки декоративная: стандартная HTML-страница не получает точный
процент загрузки игровых файлов Garry's Mod.
